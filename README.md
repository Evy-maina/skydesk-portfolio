## Sample Customer Support Work

**Customer:**  
"I've been waiting for my order and it still hasn't arrived."

**Support Response:**  
"Hi! I'm sorry for the delay and understand how frustrating this can be. Let me check the order status for you and provide you with an update as soon as possible."

### Example 2 — Product Inquiry

**Customer:**  
"Can you tell me more about this service?"

**Support Response:**  
"Absolutely! I'd be happy to help. Please let me know what you'd like to know about the service, and I'll provide you with the relevant information."
